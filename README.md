# Mohamed El Yousfi Portfolio

Static personal portfolio site built with HTML, CSS, and vanilla JavaScript.

## Structure

- `index.html` - page structure and content
- `css/style.css` - visual design and responsive layout
- `js/main.js` - interactions, sliders, animations, and contact form behavior
- `assets/` - project images and video

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## GitHub Pages

This project is ready to deploy as a static site.

1. Push the repository to GitHub.
2. In the repository settings, open `Pages`.
3. Set the source to deploy from the `main` branch and `/ (root)`.

After Pages finishes building, the portfolio will be available from your GitHub Pages URL.
